  ## 4. 对比实验

  ### 4.1 实验设置

  我们在固定的验证集上评估所提出的联合提示分割模型（Joint Model J5），并与三类提示驱动的基础模型进行比较：通用视觉分割基础模型 SAM、医学图像分割基础模型 SAM-Med2D，以及面向全切片图像场景的 WSI-SAM。所有方法采
  用相同的验证 occurrence、相同的目标类别定义和相同的像素级评价脚本。为避免利用标注信息优化提示位置，正负点均由 Phase-2 硬区域分配的实际成员像素确定；在每个区域内选择确定性代表像素作为提示点，而不参考 GT 掩
  膜。

  我们考察三种交互预算：1 个正点加 1 个负点（1+1）、3 个正点加 1 个负点（3+1）以及 5 个正点加 1 个负点（5+1）。对于每一预算，所有比较方法共享完全相同的冻结提示 manifest。1+1 协议包含 4000 个验证 episode；由于
  部分样本可用的正提示区域数量有限，3+1 和 5+1 分别包含 1261 和 885 个 eligible episode。报告像素级全局 Dice、类别宏平均 Dice、mIoU 以及容差为 2 像素的 Boundary F1。所有外部基线均使用其公开的零样本权重，并在全
  部分配 episode 上完成推理，无失败样本。

  需要说明的是，本文模型的提示编码器仅以正负点作为输入，未设计或训练 bounding-box prompt 分支。因此，本文不将 bbox 结果与点提示模型混合比较。

  ### 4.2 定量比较

  表 X 汇总了不同提示预算下的结果。总体而言，本文方法在所有提示预算和全部评价指标上均优于三种外部基线。在最具挑战性的 1+1 设置下，本文方法取得 0.7522 的全局 Dice、0.7418 的类别宏平均 Dice、0.5938 的 mIoU 和
  0.2971 的 Boundary F1。相比最优外部基线 SAM，Dice 提高 26.62 个百分点，类别宏平均 Dice 提高 27.69 个百分点。这表明，即使只给定一个目标点和一个排除点，所学习的区域表示、细胞感知特征与上下文解码机制仍能有效将
  稀疏交互信号传播至同类区域。

  随着正提示数量由 1 增加到 3 和 5，所有方法的性能均有所提升，但本文方法始终保持最佳结果。在 3+1 设置下，本文方法的全局 Dice 达到 0.8164，较 SAM 高 22.62 个百分点；在 5+1 设置下达到 0.8225，较 SAM 高 19.36 个
  百分点。与此同时，本文方法在 Boundary F1 上分别达到 0.3324 和 0.3229，明显优于各外部基线，说明其不仅提高了区域覆盖率，也更好地保持了组织边界的一致性。

  SAM 在三种外部基线中表现最强，且受益于更多正提示；WSI-SAM 紧随其后。SAM-Med2D 在当前组织学零样本设置中的表现相对较低，这说明医学领域预训练并不必然直接迁移至本任务所涉及的组织学语义和跨区域一致性要求。相比之
  下，本文方法直接针对多尺度组织区域、细胞信息和提示条件下的区域级推理进行建模，因此在低交互预算下表现出更强的适应性。
