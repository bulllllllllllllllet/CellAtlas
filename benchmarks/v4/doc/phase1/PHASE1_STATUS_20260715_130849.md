## 下一步：10x 监督分割训练代码逻辑

训练入口为 `benchmarks/v4/phase_1_multiscale/train_phase1_10x.py`，评估入口为 `eval_phase1_10x.py`。先使用固定少量 patch 做过拟合和单卡 smoke test，再启动 DDP 全量训练。

1. `SegmentationDataset` 读取 index 的一行，用 `x_level0/y_level0/width_level0/height_level0` 通过 libvips 从 HE TIFF 动态裁出并缩放到 512×512；用 `x_10x/y_10x` 从 GT 裁出同位置标签。训练增强只执行同步的旋转/翻转，避免标签插值。
2. 训练集 `BalancedPatchSampler` 按配置比例抽取 interior、boundary、rare、hard-negative 等分组；验证集保持原始分布。模型为 12 类 `DeepLabV3-ResNet50`，公共预训练 checkpoint 仅加载形状兼容的 backbone 参数，12 类分类头重新训练。
3. 优化器为 AdamW；前向使用 AMP；损失为忽略 `ignore_index=255` 的交叉熵与 Dice 加权和；每 epoch 保存 `last_checkpoint.pth`，并按 validation macro Dice 保存 `best_checkpoint.pth`。
4. 指标由混淆矩阵汇总，输出 macro Dice、每类 Dice 和背景排除后的指标；最终在从未训练的 test split 上运行 `eval_phase1_10x.py`。

## 后续工作与验收闸门

1. **Phase 1 完整验证与可解释性（下一项）**：冻结 epoch-21 的最佳 checkpoint；在 validation split 输出至少各 20 个最佳、最差和随机 patch 的 `HE | GT | prediction | overlay` 可视化，并按类别、组织面积和边界比例汇总失败模式。验收：每个结果可追溯到 WSI、patch 和 10x 坐标，重点检查血液、坏死、淋巴细胞聚集等相对困难类。
2. **一次性独立 test 评估**：在不再依据 test 修改模型、采样或训练配置的前提下，使用同一 `best_checkpoint.pth` 跑完 30 个 test 患者；除 patch 汇总指标外，按 WSI 汇总 macro 指标并保存混淆矩阵和可视化。验收：test 报告与 validation 明确分离；该步骤只在 Phase 1 方案冻结后执行一次。
3. **多尺度监督 upper bound（仍属模块一）**：以同一 200 WSI、同一患者划分和同一 test 协议，建立同中心 10x/5x/2.5x（或 1024/2048/4096 感受野）读取契约、坐标单测和对齐可视化；依次比较 `10x only`、`10x + 5x`、`10x + 5x + 2.5x`。第一版只引入简单、可审计的上下文融合，目的是验证多尺度是否提供真实增益，不提前引入 region、cell 或 prompt 模块。验收：各尺度同中心、无 GT 泄漏、所有对比使用相同 split/预算。
4. **Phase 2：深度区域化**：仅在多尺度 upper bound 明确后，构建 Deep Region Encoder；以 SLIC 作为伪标签/初始化，而不是最终固定区域，训练 soft assignment、边界、紧致性和区域纯度损失，并报告 oracle Dice、purity、区域数和边界质量。
5. **后续 Phase 3--6**：依次完成 cell-to-region attention pooling、跨尺度层级图交互、正/负 prompt set encoder、context-aware mask decoder，最后再做端到端联合微调。全程复用固定 200 WSI cohort；963 WSI 仅用于用户明确批准的最终扩展或泛化实验。

### 当前结论与后续对照设计

9 通道模型的采样 validation Dice（0.864954）比此前 10x 基线采样结果（0.862117）高约 0.00284，但**不能据此宣称三尺度有效**：三尺度索引因边界完整性过滤了 4,142 个 patch，与旧 10x 训练索引并非同一候选集。

公平 upper-bound 比较应固定使用上述 106,734 个“全尺度上下文完整”的 patch index、固定 140/30/30 WSI 划分、固定采样种子和同一验证协议，只改变输入尺度：`10x`、`10x+5x`、`10x+5x+2.5x`。test 已作为单尺度冻结结果使用；在验证集选定最终多尺度方案前，不重复查看 test。

为控制时间，下一步不应立刻各自再跑一次完整 30 epoch / 20,000 patch 预算。建议先对三组做同预算的短程筛选（例如 8 epoch、每 epoch 5,000 train / 1,000 validation patch，四卡并行；预计每组约 35--50 分钟），仅把最优尺度组合提升到完整 30 epoch 复核。这样先回答“上下文是否可能有收益”，再投入一次完整训练；未入选组合不需要跑 10 小时。
