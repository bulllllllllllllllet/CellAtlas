# V4 模块消融实验清单 — 20260725_150709

## 目标与统一规则

目标是识别每个模块带来的**独立、可泛化**增益，而不是只比较不同训练预算或不同初始化。
除另有说明外，所有 Phase 4--6 对照均遵守：

- 固定 200-WSI 开发队列、train/validation split 和同一固定 4,000-episode validation manifest；不读取 sealed test。
- 从同一个 J5 validation-best checkpoint 初始化；相同随机种子、epoch、20,000 train episodes/epoch、学习率计划及 checkpoint 规则。
- 每项保存逐 episode TP/FP/FN，并报告相对参考模型的 paired bootstrap 95% CI：Pixel macro/micro Dice、Boundary F1、unprompted Dice、prompt-conflict rate，以及按类别和 prompt-size 分层指标。
- 仅在验证集通过预先冻结的联合非劣/提升门槛后，才允许进入下一轮候选；所有运行写入新的时间戳 NFS 目录。

## 执行顺序

1. 以 A0 为冻结参考，完成 A2、A3、A4；先回答“内容相关跨尺度是否优于静态/随机边”。
2. 完成 A6、A8、A9，建立 Fine-region token 的视觉、细胞和 regionization 因果证据。
3. 完成 A10、A11、A12，验证交互与 decoder 的必要性。
4. 只有 A2 显示稳定增益后才运行 A7；否则不投入 WSI 级 cell index 的大规模工程。
5. A13 用于解释 pixel reconstruction 的边界性能，不参与主模型选择。

## 不可混用的比较

- 不把 region-level accuracy/F1 与 prompt-conditioned Pixel Dice 当作同一指标曲线。
- 不把 J10 cache adapter 与完整在线 `HierarchicalBlock` 当作同一个 Phase4 实现。
- 不把不同 initialization checkpoint、不同 episode manifest、不同预算或已读取 test 的结果用于选模。
- `hierarchical_up` 不回写 Fine token，因此不作为 Fine-mask Pixel Dice 主路线；仅用于高尺度/region-level 表征对照。
