# CellAtlas v4 阶段进展（导师汇报极简版）

更新时间：2026-07-20

## 一、项目目标

最终目标是建立一个面向病理全切片图像的通用视觉提示分割模型：用户给出少量正例和负例，模型根据这些提示找到整张图中对应的目标组织，不需要针对每个组织类别重新训练。

整个方法分为六个阶段。目前前四个阶段已经完成，后两个阶段尚未开始。

## 二、已经完成的工作

### Phase 1：建立组织分割基线和多尺度输入

**作用：** 验证 HE 图像本身能否可靠区分 12 类组织，同时建立统一的数据、坐标和多尺度读取方式。

**结果：**

- 10x 单尺度模型的 validation Dice 约为 **0.86**，说明基础组织分割是可行的。
- 冻结模型后的独立 test Dice 约为 **0.87**。
- 10x、5x、2.5x 简单拼接没有优于 10x 单尺度，因此后续暂时以 10x 为主。

**阶段结论：** 基础分割能力可靠，但简单增加尺度没有带来明确收益。

### Phase 2：把图像划分为可学习的组织区域

**作用：** 不再完全依赖固定 SLIC，而是让模型学习更符合组织语义的区域，为后续细胞融合和 prompt 匹配提供区域表示。

**结果：**

- 学习区域的纯度从 SLIC 的 **0.811** 提升到 **0.840**。
- 区域理论分割上限从 **0.384** 提升到 **0.514**。
- 边界指标与 SLIC 接近，没有明显超过 SLIC。

**阶段结论：** 学习型区域在语义一致性和理论上限上更好，但边界仍有改进空间。

### Phase 3：将细胞信息加入组织区域

**作用：** 利用 HE 图像中的细胞类型、位置、密度和细胞特征，增强组织区域的表示能力。

**结果：**

- 加入细胞后，区域分类 accuracy 从 **90.13%** 提升到 **90.93%**。
- Macro F1 从 **88.55%** 提升到 **89.12%**。
- 淋巴细胞聚集和坏死改善较明显。
- 去掉细胞输入后性能明显下降，说明模型确实使用了细胞信息。
- 血液类别仍存在漏检增加的问题，需要继续关注。

**阶段结论：** 细胞信息有效，后续模型保留细胞分支。

### Phase 4：验证跨尺度区域交互是否有效

**作用：** 让 10x、5x、2.5x 的区域交换信息，判断更大范围的组织上下文是否能够改善区域识别。

**结果：**

| 方法 | Validation accuracy |
|---|---:|
| 10x fine-only | 91.06% |
| 简单多尺度拼接 | 91.11% |
| 层级跨尺度图 | 91.05% |

三种方法差距很小，复杂跨尺度图没有超过 10x fine-only。

**阶段结论：** 跨尺度模块在当前区域分类任务上没有证明明确价值，因此暂时不加入下一阶段的默认模型。

## 三、目前得到的总体结论

1. HE 图像能够支持较可靠的 12 类组织分割，基础 Dice 约为 0.86。
2. 学习型区域比固定 SLIC 具有更好的语义一致性和理论分割上限。
3. 细胞信息能够改善组织区域表示，应当保留。
4. 简单多尺度和复杂跨尺度图都没有带来明确收益，暂时使用更简单的 10x 单尺度路径。

当前冻结的主路径为：

```text
10x HE图像
→ 学习型组织区域
→ 注入细胞信息
→ 细胞感知的区域表示
```

## 四、后面还需要做什么

### Phase 5：Prompt encoder

让模型理解用户给出的正例和负例，明确“当前要寻找哪一种组织”。这一阶段主要验证：多个正负提示是否比简单取平均更有效。

### Phase 6：Mask decoder

将 prompt 信息和组织区域结合，输出最终的像素级二值分割结果。这一阶段才会得到完整 v4 系统的 prompt-conditioned Dice、mIoU 和提示效率指标。

### 最终需要回答的问题

- 用户只给一个正例时，模型能否找到同类组织？
- 加入负例后，误检是否减少？
- 增加 prompt 数量后，Dice 能否稳定提高？
- 模型能否在未参与训练的病人和切片上保持效果？

## 五、一句话汇报总结

前四个阶段已经完成：基础组织分割可行，学习型区域和细胞信息有效，但跨尺度交互没有带来明确提升；下一步将基于 10x 细胞感知区域表示，训练正负视觉 prompt 驱动的最终组织分割模型。
