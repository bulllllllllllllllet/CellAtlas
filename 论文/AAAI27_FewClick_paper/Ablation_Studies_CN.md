4.1消融实验

4.1.1 实验设置
数据划分
我们在由 200 张 H&E WSI 构成的开发队列上进行模型训练与消融分析。其中，140 张 WSI 用于训练，30 张用于验证，其余 30 张作为独立测试集。所有数据均按照 WSI 级别划分，确保来自同一张切片的图像区域不会同时出现在不同数据子集中。
在模型开发阶段，测试集始终保持封存，不参与超参数选择、模型选择或消融分析。本文报告的 Phase 2、Phase 3 和 Phase 4 消融结果均来自固定的 30 张验证 WSI。最终模型、二值化阈值及报告规则冻结后，我们仅在独立测试集上执行一次完整评估。
情景式训练与验证
FewClick 采用提示条件化的情景式训练。每个训练 episode 包含一个 WSI 图像区域、一种当前目标组织、一个或多个正提示、可选的困难负提示，以及该目标组织相对于其余区域的二值掩膜。不同 episode 中的目标组织不断变化，使模型学习根据当前视觉提示推断分割任务，而不是依赖固定类别对应的输出通道。
除特别说明外，所有消融实验采用相同的数据划分、随机种子、数据增强策略和优化计划，每轮训练包含 20,000 个 episode。模型统一在固定的 4,000-episode 验证清单上评估，以避免不同提示采样导致的比较偏差。完整模型及各消融变体均使用一致的验证协议，模型选择以 Pixel Macro Dice 为主要依据。
对于会显著改变输入表示分布的消融，例如移除可学习区域化或细胞感知分支，我们重新训练所有直接依赖该模块的下游组件，而不是简单地将相应特征置零后复用完整模型的预测头。这一设置避免将输入分布突变或预测头失配错误地解释为被移除模块的贡献。
评价指标
我们使用 Pixel Macro Dice、Pixel Micro Dice 和 Boundary F1 评价模型性能。
Pixel Macro Dice 首先分别计算每个 episode 的像素级 Dice，再对所有 episode 等权平均。该指标能够避免大面积目标组织主导最终结果，是本文的主要评价指标。
Pixel Micro Dice 汇总所有验证 episode 的真阳性、假阳性和假阴性像素后统一计算 Dice，更强调模型在整体像素分布上的分割能力。
Boundary F1 衡量预测边界与真实组织边界的一致性，用于评估模型对细小结构和复杂组织轮廓的恢复能力。所有方法使用相同的边界匹配容差。
对于区域化消融，我们还报告 prompt-conflict rate，即正提示和负提示被映射至同一硬区域的 episode 比例。较高的冲突率表明区域划分过于粗糙，难以准确承载用户的正负交互意图。

4.3 可学习区域化的贡献
为分析学习式组织区域的作用，我们使用固定 SLIC 超像素替换 Phase 2 中的可微软区域分配。为了控制区域表示规模，SLIC 对照仍采用 64 个区域槽位和 256 维区域 token，并保留相同的视觉编码器、细胞输入、提示编码路径和掩膜解码器。所有直接受区域表示变化影响的下游组件均重新训练。
使用固定 SLIC 后，Pixel Macro Dice 从 0.7413 降至 0.5650，绝对下降 0.1763；Pixel Micro Dice 从 0.8138 降至 0.6482，下降 0.1656；Boundary F1 从 0.3142 降至 0.1475，下降 0.1667。由于两种设置具有一致的区域数量和特征维度，该性能差异不能简单归因于模型容量或 token 数量的变化。
固定 SLIC 的 prompt-conflict rate 达到 0.5645，即超过一半的验证 episode 中，至少一组具有相反语义的提示被压缩到同一个硬区域。这说明由颜色和局部纹理预先确定的超像素不仅限制组织边界的表达能力，还会破坏提示与区域之间的精确对应关系。相比之下，可学习区域能够在下游分割监督下调整像素归属，使区域边界更加符合组织结构，并为正负提示提供更细致的空间支持。
值得注意的是，固定 SLIC 对 Boundary F1 的影响尤其明显。该结果表明，可学习区域化不仅提升区域级语义识别，还直接改善了复杂组织轮廓和狭窄边界的恢复能力。

4.4 细胞感知区域表征的贡献
为验证细胞信息是否为组织识别提供了超出颜色和纹理的补充证据，我们移除 Phase 3 中的 Cell-to-Region Attention、细胞密度及相关统计特征，仅保留视觉区域 token。随后，使用相同训练预算重新训练提示编码器和掩膜解码器。
移除细胞感知融合后，Pixel Macro Dice 从 0.7413 降至 0.5885，下降 0.1528；Pixel Micro Dice 从 0.8138 降至 0.6543，下降 0.1595；Boundary F1 从 0.3142 降至 0.2471，下降 0.0671。该结果表明，FewClick 的目标组织识别并非仅依赖宏观颜色和纹理。细胞形态表征、区域细胞密度以及细胞组成上下文，为区分视觉外观相似但微观构成不同的组织提供了关键依据。
与固定 SLIC 消融相比，移除细胞分支对 Boundary F1 的影响相对较小，但对整体 Dice 的影响仍然显著。这一差异反映了两个模块的互补作用：可学习区域化主要决定组织区域的空间支持范围和边界质量，而细胞感知融合主要增强区域内部的微观语义表示。只有同时建模区域边界和细胞组成，模型才能获得稳定的组织级判别能力。

---
4.5 多尺度层级交互的贡献
为分析跨尺度上下文的作用，我们构建 FineOnly 对照，仅保留细粒度区域及其局部视觉和细胞表征，移除中粒度、粗粒度区域以及相应的父子层级交互。提示编码器和掩膜解码路径保持不变。
FineOnly 的 Pixel Macro Dice 为 0.6384，相比完整模型下降 0.1029；Pixel Micro Dice 从 0.8138 降至 0.6929，下降 0.1209；Boundary F1 从 0.3142 降至 0.2630，下降 0.0512。该结果表明，仅依赖细粒度区域不足以稳定判断组织身份。
细粒度区域能够保留局部细胞形态和组织边界，但其物理视野有限，难以描述腺体排列、组织邻接关系及更大范围的组织构型。完整模型通过细—中—粗层级之间的稀疏信息交换，将局部细胞证据向上汇总，并将宏观组织上下文返回细粒度预测。超过 0.10 的 Macro Dice 差距说明，跨尺度交互并非冗余结构，而是从局部提示理解完整组织概念的重要组成部分。
同时，FineOnly 的 Boundary F1 下降幅度小于其 Dice 降幅，说明细粒度区域仍能提供一定的局部轮廓信息，但在判断哪些区域属于当前目标组织时更容易产生遗漏和误检。因此，多尺度层级交互的主要贡献体现在组织语义判别和远距离目标区域召回，而不仅是局部边界细化。

4.6 集合式提示编码的贡献
为验证 Prompt Set Encoder 对多提示信息整合的作用，我们将正、负提示 token 的 Transformer 集合编码器替换为 masked mean prototype。该对照仍保留提示极性、归一化坐标、提示类型和提示尺寸编码，并使用相同的区域匹配器与图解码器。受影响的提示编码后半部分和掩膜解码模块按照与其他消融一致的训练预算重新训练。
Mean prototype 对照的 Pixel Macro Dice、Pixel Micro Dice 和 Boundary F1 分别为 [待填]、[待填] 和 [待填]。与完整模型相比，Pixel Macro Dice 下降 [待填，预期超过 0.10]，Pixel Micro Dice 下降 [待填]，Boundary F1 下降 [待填]。
该结果表明，简单均值原型难以充分描述多个局部提示之间的互补性和差异性。当正提示覆盖目标组织的不同形态模式，或负提示来自多个容易混淆的组织区域时，均值操作会将这些局部证据压缩为单一中心表示，导致具有判别力的提示模式被平滑。相比之下，集合式编码器能够以置换不变的方式建模提示之间的关系，并在保留提示极性的同时自适应聚合不同局部证据。
我们进一步在多提示 episode 和包含困难负提示的 episode 上进行分组分析。集合式提示编码器在多提示子集上的 Pixel Macro Dice 为 [待填]，相比 mean prototype 提升 [待填]；在困难负提示子集上的提升为 [待填]。更显著的子集差异说明，Prompt Set Encoder 的主要作用不是处理单个简单提示，而是在复杂交互中建模互补或冲突的视觉证据。

4.7 消融实验总结
模块级消融表明，FewClick 的性能来源于多个相互补充的设计。将可学习区域替换为固定 SLIC 带来最大的性能下降，说明能够根据分割目标调整的区域划分对于组织边界建模和提示—区域对齐至关重要。移除细胞感知融合导致相近幅度的 Dice 下降，证明微观细胞组成是宏观组织外观之外的重要判别依据。仅保留细粒度区域同样造成超过 0.10 的 Macro Dice 下降，说明中、粗尺度上下文对于完整组织概念的识别不可缺少。Prompt Set Encoder 的消融进一步表明，显式建模多个正负提示之间的关系优于简单均值原型，尤其适用于多提示和困难负提示情景。
综合来看，可学习组织区域提供空间支持，细胞感知融合补充区域内部的微观组成，多尺度层级交互引入宏观组织上下文，而集合式提示编码负责从有限交互中构建当前目标概念。四个模块分别对应边界、细胞、上下文和用户意图，缺少任一部分都会削弱少量提示驱动的全图组织分割能力。
