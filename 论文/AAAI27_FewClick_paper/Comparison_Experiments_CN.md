# 4 对比实验

我们将 FewClick 与 SAM、SAM-Med2D 和 WSI-SAM 进行比较。实验包括两部分：一是在固定 patch episode 上比较相同提示条件下的局部分割能力；二是在完整 WSI 上比较少量提示驱动的全图组织分割能力。所有外部模型均采用公开预训练权重，不在本文数据上额外微调。

## 4.1 Patch episode 级比较

### 4.1.1 实验设置

每个 episode 包含一个 (512\times512) 图像块、一个目标组织、对应的二值掩膜及固定正负点提示。同一提示预算下，所有方法使用完全相同的 episode 和提示坐标。

我们设置三种交互预算：(1+1)、(3+1) 和 (5+1)，分别表示 1、3、5 个正点及 1 个负点。三种协议分别包含 4,000、1,261 和 885 个有效 episode。评价指标包括全局 Dice、类别宏 Dice、mIoU 和容差为 2 像素的 Boundary F1。此外，我们报告单张 patch 的模型前向吞吐量（FPS）。

### 4.1.2 总体结果

**表 1：不同提示预算下的 patch episode 级结果。FPS 表示每秒处理的 (512\times512) patch 数。**

| 提示预算  | Episodes | 方法             |    全局 Dice |   类别宏 Dice |       mIoU | Boundary F1 |             FPS |
| ----- | -------: | -------------- | ---------: | ---------: | ---------: | ----------: | --------------: |
| (1+1) |    4,000 | SAM            |     0.4860 |     0.4649 |     0.3094 |      0.1369 |           11.10 |
|       |          | SAM-Med2D      |     0.2119 |     0.2318 |     0.1379 |      0.0954 |           35.20 |
|       |          | WSI-SAM        |     0.4154 |     0.4064 |     0.2653 |      0.1353 |           22.22 |
|       |          | **FewClick** | **0.7522** | **0.7418** | **0.5938** |  **0.2971** | (\geq4.95^\ast) |
| (3+1) |    1,261 | SAM            |     0.5903 |     0.5805 |     0.4143 |      0.1763 |           11.10 |
|       |          | SAM-Med2D      |     0.3178 |     0.3323 |     0.2089 |      0.0980 |           35.20 |
|       |          | WSI-SAM        |     0.5623 |     0.5608 |     0.3976 |      0.1676 |           22.22 |
|       |          | **FewClick** | **0.8164** | **0.8159** | **0.6913** |  **0.3324** | (\geq4.95^\ast) |
| (5+1) |      885 | SAM            |     0.6290 |     0.6243 |     0.4585 |      0.1956 |           11.10 |
|       |          | SAM-Med2D      |     0.4050 |     0.4149 |     0.2706 |      0.1091 |           35.20 |
|       |          | WSI-SAM        |     0.6041 |     0.6057 |     0.4397 |      0.1764 |           22.22 |
|       |          | **FewClick** | **0.8225** | **0.8206** | **0.6978** |  **0.3229** | (\geq4.95^\ast) |

(\ast) FewClick 的 FPS 根据包含评估开销的双分支运行时间估算，因此为保守下界。

总体上，FewClick 在三种提示预算和全部指标上均优于外部基线。在最具挑战性的 (1+1) 设置下，FewClick 的全局 Dice 和类别宏 Dice 分别达到 0.7522 和 0.7418，较最佳外部基线 SAM 分别提高 0.2662 和 0.2769。随着正提示数量增加，FewClick 在 (3+1) 和 (5+1) 设置下的性能进一步提升，并始终保持最优。

从纯模型前向速度看，FewClick 慢于三个 SAM 基线，但其多尺度区域 token 和细胞特征可离线预计算。在完整评估流程中，FewClick 完成 4,000 个 episode 的总时间仍短于三个外部基线，因此纯前向 FPS 并不能完全代表实际交互系统的端到端效率。

### 4.1.3 同一公共子集上的提示数量曲线

由于 (1+1)、(3+1) 和 (5+1) 三种协议的 eligible episode 数量不同，表 1 中跨预算结果不能直接解释为“增加提示点数量”带来的纯粹性能增益。为此，我们进一步在三种预算**共同可用的同一子集**上进行严格比较。该子集包含 **885 个评估 occurrence**，对应 **819 个唯一 patch**；三档设置使用完全相同的 occurrence、真实掩膜、目标类别和负点，仅正提示数量不同，分别取冻结 5 点序列的前 1、3 和 5 个正点。

**图 4** 展示了四种方法在该共同子集上的类别宏 Dice 随正提示数量变化的趋势；其余指标与图中趋势一致。

**图 4：在同一 885 个 occurrence 公共子集上，不同方法的类别宏 Dice 随正提示数量变化的折线图。三档设置共享相同的 occurrence、GT、类别和负点，仅正提示数量不同。**

在这一严格控制变量的比较下，外部基线均随着正提示数量增加而持续改善。例如，SAM 的类别宏 Dice 由 (1+1) 时的 0.5292 提升至 (3+1) 的 0.5911，再提升至 (5+1) 的 0.6243；WSI-SAM 也由 0.4222 提升到 0.5611 和 0.6057。相比之下，FewClick 在 (1+1) 时已达到 0.7888，在 (3+1) 时进一步提升至 0.8292，并在 (5+1) 时略降至 0.8206，但仍显著高于所有外部基线。

这一结果表明，FewClick 对提示数量的收益并非单调增长，其最佳 Dice 出现在 (3+1) 设置，相较 (1+1) 提升了 0.0404；从 (3+1) 到 (5+1)，类别宏 Dice 略有下降 0.0086，但 Boundary F1 从 0.3220 小幅提升至 0.3229。这说明对于 FewClick 而言，3 个正提示可能已经足以较完整地定义目标组织语义，继续增加提示点带来的收益接近饱和，甚至可能因局部冗余或轻微噪声而对区域重叠指标产生扰动。总体而言，在三档设置下，FewClick 始终明显优于最强外部基线 SAM。

## 4.2 WSI 级全图比较

### 4.2.1 实验设置

我们进一步在 10 张 WSI 上评估十二类组织的全图分割性能。十二类组织在所有 WSI 中均存在，因此不存在缺失类别记零的问题。

对于 FewClick，每个 WSI–类别生成 5 组“1 正点 + 1 负点”候选，每组提示直接产生整张 WSI 的分割结果，并使用真实掩膜选择其中 Dice 最高者。该协议共包含 (10\times12\times5=600) 次候选推理，全部成功返回掩膜。

对于 SAM、SAM-Med2D 和 WSI-SAM，我们仅在包含目标组织的 patch 上调用模型，每个 patch 使用一个正点和可用时的一个负点，最后拼接得到全图结果。

该实验中的两类协议均使用了 oracle 信息：FewClick 使用真实掩膜选择最佳候选，三个基线使用真实掩膜筛选目标阳性 patch。因此，WSI 级结果主要反映不同推理范式下的全图可达性能，而严格公平比较仍以 patch episode 结果为主。

### 4.2.2 全图结果

**表 2：10 张 WSI 上十二类组织的全图分割结果。**

| 方法             |   类别宏 Dice |   类别宏 mIoU | 类别宏 Precision | 类别宏 Recall |   像素微 Dice |
| -------------- | ---------: | ---------: | ------------: | ---------: | ---------: |
| **FewClick** | **0.7495** | **0.6383** |    **0.7456** | **0.7676** | **0.9237** |
| SAM            |     0.4082 |     0.3158 |        0.3474 |     0.6821 |     0.7000 |
| SAM-Med2D      |     0.3901 |     0.3095 |        0.4580 |     0.4966 |     0.6651 |
| WSI-SAM        |     0.4342 |     0.3245 |        0.4892 |     0.4146 |     0.7418 |

FewClick 的类别宏 Dice 为 0.7495，较最优外部基线 WSI-SAM 提高 0.3153；类别宏 mIoU 和像素微 Dice 分别提高 0.3138 和 0.1819。SAM 具有较高 Recall，但 Precision 较低，说明其更容易产生大范围假阳性；相比之下，FewClick 在 Precision 和 Recall 之间更为均衡。

在调用规模方面，FewClick 共执行 600 次全图候选推理，而三个 SAM 基线分别需要在 23,642 个目标阳性 patch 上调用模型。这说明 FewClick 可以通过少量全局提示直接完成整图传播，而逐 patch 方法需要大量局部调用。

## 4.3 小结

在相同 patch、提示位置和交互预算下，FewClick 在 Dice、mIoU 和 Boundary F1 上均明显优于 SAM、SAM-Med2D 和 WSI-SAM。进一步地，在共同 885 个 occurrence 子集上的严格比较表明，FewClick 在不同提示数量下始终优于外部基线，并在 (3+1) 设置下达到最佳性能。WSI 级实验则说明，FewClick 能够将少量局部提示传播至整张切片，在十二类组织上取得更高的全图分割精度，并显著减少局部模型调用次数。
